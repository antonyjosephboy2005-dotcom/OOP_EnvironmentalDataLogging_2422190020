# Stage 1 – Environmental Data Logging System Design

## Objective
Design an OOP-based system to simulate environmental monitoring.

## Core Classes
- Sensor
- Measurement
- EnvironmentZone
- DataLogger
- AlertSystem

## Relationships
- Sensors generate Measurements
- Measurements are stored inside Zones
- DataLogger manages sensors and zones
- AlertSystem checks unsafe values

## OOP Principles
- Encapsulation
- Composition
- Separation of concerns
